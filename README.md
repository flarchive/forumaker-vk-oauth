# ✨ VK OAuth for Flarum
Adds a VK ID OAuth provider for [FoF OAuth](https://github.com/FriendsOfFlarum/oauth). Supports **Flarum 2.x**

![License](https://img.shields.io/badge/license-MIT-blue) ![Packagist Version](https://img.shields.io/packagist/v/forumaker/vk-oauth) ![Downloads](https://img.shields.io/packagist/dt/forumaker/vk-oauth)

## 🚀 Features
- ⚙️ VK ID login via FoF OAuth
- 🎨 Styled login button for the forum frontend


## 📦 Installation
Run this in your Flarum root directory:

```
composer require forumaker/vk-oauth:"*"
```


## 🛠️ Configuration
1. Create an application at `https://id.vk.ru/about/business/go/accounts`
2. Set the callback URL to `https://your-forum.ru/auth/vk`
3. Enter your Client ID and Secure key in the FoF OAuth provider settings
